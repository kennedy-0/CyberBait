## 📖 Sobre o projeto

O **CyberBait 1.0** é um projeto desenvolvido em Python com o objetivo de estudar conceitos relacionados a servidores HTTP, páginas web, formulários e conscientização sobre ataques de engenharia social.

A proposta é oferecer um ambiente controlado para demonstrações educacionais de como páginas falsas podem ser utilizadas em ataques de phishing, ajudando estudantes e profissionais de tecnologia a compreender os riscos e desenvolver práticas de segurança digital.

> ⚠️ **Aviso:** Este projeto destina-se exclusivamente a estudos e ambientes autorizados. Não utilize páginas que imitem serviços reais para coletar credenciais, nem armazene senhas de terceiros.

## 📌 Funcionalidades

- 🌐 Servidor HTTP local desenvolvido em Python.
- 🔌 Escolha personalizada da porta de execução.
- 🔄 Seleção automática de outra porta quando a escolhida estiver ocupada.
- 📊 Animação de carregamento no terminal.
- 🎨 Interface de terminal com cores ANSI.
- 📋 Menu interativo para selecionar demonstrações.
- 🧪 Estrutura modular para futuras simulações educacionais.
- 🖥️ Exibição do endereço local para acessar as demonstrações.

## 💻 Como funciona

Ao iniciar o programa, o usuário escolhe uma porta para o servidor HTTP.

O sistema realiza uma animação de carregamento e inicia o servidor.

Em seguida, apresenta um menu interativo no terminal com opções de demonstração.

O projeto utiliza uma estrutura baseada em manipuladores HTTP para responder às requisições recebidas.

## 🔍 Conceitos estudados

- Funcionamento do protocolo HTTP.
- Diferenças entre requisições GET e POST.
- Funcionamento de servidores web.
- Processamento de formulários HTML.
- Comunicação entre frontend e backend.
- Engenharia social e conscientização sobre phishing.
- Importância da proteção de informações sensíveis.

## 🔐 Segurança e uso responsável

Este projeto possui finalidade exclusivamente educacional.

Para publicação e utilização segura, as demonstrações devem:

- Utilizar páginas fictícias, sem imitar marcas ou serviços reais.
- Não solicitar nem armazenar senhas verdadeiras.
- Utilizar dados fictícios nos testes.
- Operar somente em ambientes controlados e autorizados.
- Informar claramente aos participantes quando estiverem em uma simulação.

## 📚 Objetivo educacional

O principal objetivo do CyberBait é contribuir para o aprendizado de programação Python, desenvolvimento de servidores HTTP e fundamentos de segurança da informação.

O projeto também busca demonstrar a importância da identificação de páginas suspeitas e da proteção de credenciais na internet.

Desenvolvido como projeto de estudos em Python e cibersegurança.
